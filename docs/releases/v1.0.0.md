# kbshare 1.0.0

首个正式版本，支持 Windows / Linux 键盘共享、TLS 加密连接、独立剪贴板同步、
Logitech Easy-Switch、设备布局同步与浏览器配置向导。

本版本包含文件剪贴板延迟传输：小于 10 MiB 的文件组立即同步，较大文件组在目标应用读取时传输。
Windows 使用 OLE，Linux 使用 X11 selection 或 Wayland ext/wlr data-control。

## 下载与使用

- Windows x64：下载 `kbshare-v1.0.0-x86_64-pc-windows-msvc.zip`。
- Linux x64：下载 `kbshare-v1.0.0-x86_64-unknown-linux-gnu.tar.gz`，适用于 Ubuntu 24.04 或兼容系统（glibc 2.39+）。
- `SHA256SUMS` 包含以上压缩包的 SHA-256 校验值。

压缩包包含 `kbshare`、`kbshare-registry`、`kbshare-flow`、`kbshare-config`、
配置样例和文档。Linux 包还附带 udev / Polkit 规则。
Linux 运行时需要 udev、D-Bus、X11/XCB 或 Wayland 环境，推荐先安装
`libudev1 libdbus-1-3 libx11-6 libxcb1 libwayland-client0 xdg-utils`。
首次运行 `kbshare` 按配置向导完成设置；详情见随包 README。

## 升级与已知限制

- 两端须同时更新并重启：剪贴板协议 v5 与 v3/v4 不兼容。
- 延迟文件传输要求源机器保持连接；复制新内容或断开连接会取消尚未完成的下载。
- Wayland 延迟文件读取要求合成器支持 ext/wlr data-control；剪贴板管理器读取也可能触发传输。
- 目录不参与文件共享；真实硬件和桌面授权需按 `docs/manual_test.md` 验证。

CI 在 Linux / Windows 上执行自动测试与 release 构建，不替代真实双机联调。
