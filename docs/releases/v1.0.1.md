# kbshare 1.0.1

本次更新调整主程序日志，协议与 1.0.0 兼容。

- 关闭捕获、转发、接收和注入路径中的逐键日志，包括键码和按下、释放动作；开启 `RUST_LOG=debug` 或 `trace` 也不会恢复这些记录。
- 每个 UTC 日期使用一个 `logs/kbshare.YYYY-MM-DD.log` 文件，同日重启继续追加。
- 保留当天及前 6 天的日志。程序启动时及运行期间每分钟检查并删除过期日志，空闲时同样执行；程序关闭期间的过期日志会在下次启动时清理。
- 旧版 `kbshare.log` 不再追加，最后修改时间满 7 天后清理。清理不会删除其他文件或目录。

## 下载

- Windows x64：`kbshare-v1.0.1-x86_64-pc-windows-msvc.zip`
- Linux x64：`kbshare-v1.0.1-x86_64-unknown-linux-gnu.tar.gz`（Ubuntu 24.04 或兼容系统，glibc 2.39+）
- `SHA256SUMS`：两个压缩包的 SHA-256 校验值。

退出旧程序后替换可执行文件并重新启动，保留原有配置、证书和信任库。
两台机器分别升级后，各自的日志调整才会生效。
